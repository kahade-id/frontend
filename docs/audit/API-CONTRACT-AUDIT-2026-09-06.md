# Explainer — Re-enabling the Kahade API contract audit (mobile OpenAPI spec)

> [!NOTE]
> **TL;DR** — The complaint was "almost no endpoints load." A deep static audit of all **231** frontend API calls against the backend's **313**-route OpenAPI contract found **zero mismatches**: paths, methods, query params, request-DTO constraints, and response envelopes are all in sync. The one real repo defect was that the *mobile* OpenAPI spec had gone missing (the full backend export was committed under the wrong name and the explaining README was deleted), which silently **disabled the strict contract audit** in CI. This PR restores that audit and makes it reproducible. It does **not** change any endpoint — because none were broken at the contract level.

## Background

Kahade's mobile app (Expo / React Native) talks to a NestJS backend. Every network call goes through a single boundary in `lib/api/client.ts` and a set of typed adapters in `lib/api/*.ts` (`api.orders.listOrders(...)`, `api.wallet.getWallet(...)`, and so on). Each adapter calls `http.get/post/...` with a literal path like `/v1/orders`.

The backend describes itself with an OpenAPI document generated by `@nestjs/swagger`. The frontend uses that document as a **contract** in three build-time scripts:

- `scripts/gen-api-types.mjs` → generates `lib/api/types.ts` (request DTO types)
- `scripts/gen-api-constraints.mjs` → generates `lib/api/constraints.ts` (runtime min/max/length rules)
- `scripts/audit-inventory.mjs` → checks that **every** `http.*` call maps to a documented `METHOD /path`

> [!IMPORTANT]
> **The contract file.** All three scripts read one file: `docs/api/kahade-api-mobile.json`. If it is absent, the scripts either fail or are skipped, and the frontend loses its only automated defense against calling an endpoint the backend doesn't actually expose.

To keep a permanently-red pipeline from hiding *other* failures, someone wrapped the audit in `scripts/check-api.mjs` ("soft" mode): if the spec file is missing, print a warning and exit 0. `npm run check` used that soft wrapper.

### What had gone wrong

Two commits, minutes apart, from the `kahade-id` account:

- `db42591 Add files via upload` — added the backend's **full** export as `docs/api/openapi.json` (313 paths, including 93 `/v1/admin/*` routes the mobile app never calls).
- `9fe023c Delete docs/api/README.md` — removed the note explaining that the tooling needs `docs/api/kahade-api-mobile.json`.

So the spec was present but under the wrong name. The tooling's expected file didn't exist, `check-api.mjs` took the "soft" branch, and the contract audit stopped running — quietly.

## Intuition

Think of two guest lists. The backend prints the **full building** guest list (everyone, including the admin floor). The mobile app only needs the list for the **public floors**. The tooling was told "the list you need is called `kahade-api-mobile.json`." Someone taped up the full-building list under a different title and threw away the sign explaining the difference. The bouncer (the audit) shrugged and waved everyone through without checking.

The fix is to derive the mobile list from the full one by crossing off the admin floor, and to keep the derivation as a script so it can't drift:

```
openapi.json (313 paths)  ──drop every /admin path──▶  kahade-api-mobile.json (220 paths)
```

Why dropping `/admin` is exactly right, not a guess: regenerating the committed types from "full minus admin" reproduces `lib/api/types.ts` **byte-for-byte** (87 request DTOs; the 28 admin-only DTOs like `BanUserDto`, `WalletAdjustDto`, `CreateVoucherDto` fall away), and `lib/api/constraints.ts` byte-for-byte too. That equality is the proof that the mobile contract == full contract minus admin.

> [!TIP]
> **The important negative result:** with the spec back in place, the strict audit reports *231 adapter calls match documented methods/paths*. There is no frontend call to a nonexistent route. Whatever "doesn't load" on the user's device is therefore **not** a frontend↔backend contract mismatch.

## Code

**1. A reproducible generator — `scripts/gen-mobile-spec.mjs` (new).** Derives the mobile spec from the full export by dropping admin paths; `--check` fails CI if the committed file is stale.

```js
const isAdminPath = (url) => url.includes("/admin")
const full = JSON.parse(readFileSync(sourcePath, "utf8"))
const paths = {}
for (const [url, verbs] of Object.entries(full.paths))
	if (!isAdminPath(url)) paths[url] = verbs
const content = JSON.stringify({ ...full, paths }, null, 2) + "\n"
```

**2. The derived artifact — `docs/api/kahade-api-mobile.json` (new, 220 paths).** Committed so CI is hermetic (no cross-repo fetch needed).

**3. `docs/api/README.md` (restored).** Documents that `openapi.json` is the raw backend export and `kahade-api-mobile.json` is derived from it, plus the regeneration steps.

**4. `package.json` — wiring (the behavioral change).**

```diff
- "gen:api": "node scripts/gen-api-types.mjs && node scripts/gen-api-constraints.mjs",
+ "gen:spec": "node scripts/gen-mobile-spec.mjs",
+ "gen:api": "node scripts/gen-mobile-spec.mjs && node scripts/gen-api-types.mjs && node scripts/gen-api-constraints.mjs",
+ "check:spec": "node scripts/gen-mobile-spec.mjs --check",
- "check": "... && npm run check:api:soft && ...",
+ "check": "... && npm run check:spec && npm run check:api && ...",
```

`npm run check` now runs the **strict** `check:api` (was `check:api:soft`) plus `check:spec`, so a future missing/stale spec turns CI red instead of silently skipping. `lib/api/types.ts` and `lib/api/constraints.ts` are unchanged — they already matched.

## Verification

> [!NOTE]
> Every gate below was run in a clean `npm ci` checkout on Node 22.

- **Contract diff (custom):** 173 literal adapter calls → **0** with no matching backend route.
- **Strict `check:api`:** `API inventory OK: 231 adapter calls match documented HTTP methods/paths; 82 screens inventoried.`
- **Determinism:** `npm run gen:api` regenerates `types.ts` (87 DTOs) + `constraints.ts` **identical** to the committed files (`git diff` empty).
- **`npm run check`:** exit 0 — typecheck, lint, tokens, a11y, screens, inventory, **spec**, **api (strict)**, weblinks, push, and **230/230 tests**.
- **`npm run build:web`:** `Exported: dist`, **98 static routes** — the app bundles and renders.

**Manual QA:**
1. `cd frontend && npm ci`
2. `npm run gen:api` → confirm `git status` shows no change to `lib/api/types.ts` / `constraints.ts`.
3. `npm run check:spec` → `Mobile spec sinkron: 220 path (buang 93 path admin).`
4. `npm run check` → exit 0.
5. Temporarily `rm docs/api/kahade-api-mobile.json` and rerun `npm run check` → it now **fails** at `check:spec` (proving the audit is no longer skippable).
