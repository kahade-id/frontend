## Bagian A — Atribut aksesibilitas duplikat di JSX (TS17001)

Bukti: `npx tsc --noEmit` melaporkan `error TS17001: JSX elements cannot have
multiple attributes with the same name` di 40 elemen. Pola seragam: ada dua
atribut `accessibilityRole` pada elemen yang sama — `accessibilityRole="button"`
(injeksi) mendahului atribut `accessibilityRole` asli yang lebih spesifik
(`menuitem`, `tab`, `radio`, `checkbox`, `imagebutton`, `link`, `search`,
`text`, `none`, `button`). Alasan umum: JSX/TS melarang atribut ganda; layar
bantuan (screen reader) membaca peran yang salah/ambigu; ekspektasi peran
semantik komponen (mis. item menu = `menuitem`, sel tanggal = `button`) tidak
terpenuhi. Perbaikan: atribut duplikat pertama dihapus, atribut asli
dipertahankan.

## Bagian B — Deklarasi mati sisa refactor (TS6133/TS6192)

Bukti: tsc melaporkan simbol diimpor/dideklarasikan tetapi tidak pernah dibaca.
Akar masalah: animasi berbasis RN `Animated.timing(...)` di komponen-komponen
ini sudah dipusatkan ke `useOverlayPresence()` (yang menghormati
`prefers-reduced-motion` secara terpusat, lihat `components/ui/backdrop.tsx:62-65`)
atau dipindah ke reanimated gesture, sehingga `motionDuration`, `useReducedMotion`,
`const reducedMotion`, `tokens`, dan `MAX_WIDTH_MD` yang tersisa adalah sisa
refactor. Alasan umum: kode mati membingungkan pembaca (menyiratkan durasi
animasi diatur di tempat yang salah), dan `npm run check` gagal karena tsc
`noUnusedLocals` aktif (tsconfig). Perbaikan: hapus deklarasi yang tidak
terpakai; perilaku reduced-motion tetap dijamin `useOverlayPresence`.

## Bagian D — Pemeriksaan dalam-dalam yang **bersih** (bukan temuan)

Agar tidak ada klaim tanpa bukti, berikut titik-titik rawan yang diperiksa dan
dinyatakan **tidak bermasalah** (dengan bukti):

1. `lib/api/client.ts` — refresh token single-flight per revisi sesi
   (`refreshInFlight`, baris ~215-263); 401 memicu refresh sekali; 429/5xx
   tidak logout; dedupe GET in-flight; timeout membatalkan fetch
   (`bounded()`); idempotency key UUIDv4 untuk mutasi; path absolut dilarang
   (`buildUrl`). Aman.
2. `lib/api/session.ts` — antrean tulis berurutan (`writeInOrder`), cache token
   di-invalidate pada perubahan revisi, `startSession` menghapus state PIN/biometrik
   akun lama sebelum menyimpan token baru. Aman.
3. `lib/secure-storage.ts` — web hanya mem-persist 4 kunci non-rahasia
   (`WEB_PERSISTENT_KEYS`); JWT/PIN/push token memory-only. Sesuai klaim README.
4. `lib/format.ts` — parser Rupiah menolak desimal ("10.000,50" → NaN, bukan
   1.000.050); `parseRupiahPartial` membedakan separuh ketikan vs desimal
   tempel; tidak ada `Intl` (Hermes deterministik). Aman.
5. `lib/financial.ts` — validasi nominal `Number.isSafeInteger` (Rupiah bulat)
   dengan batas dari constraint API. Aman.
6. `app/(auth)/verify-otp.tsx:219` — `console.debug` sudah dibungkus `__DEV__`.
7. `lib/api/auth.ts` — `(result as any)` hanya untuk fallback snake_case yang
   didokumentasikan; eslint `no-explicit-any` sengaja off dengan alasan di
   `eslint.config.mjs`. Aman.
8. Penjepit angka (`Math.min(Math.max(...))`) di 20+ lokasi (tooltip, grid,
   currency-range, bar-chart, range-slider, dst.) — urutan argumen benar semua.
9. `usePolling`/`useOverlayPresence` membersihkan timer & listener (unmount,
   blur, AppState, visibilitychange). Tidak ada interval bocor.
10. Assets: `app.json` merujuk asset yang ada; font 7/7 ada; `public/.well-known`
    (AASA + assetlinks) ada; `check:weblinks` hijau untuk 18 route dinamis.
11. `lib/api/*` fungsi tanpa pemanggil (`verifyEmailByLink`, `getChatAttachments`,
    `getExchangeRates`, `getMyDashboard`, `cleanupUploads`, `uploadDirect`,
    `fileKeyToUrl`, `getNotification`, `getTransactionTemplate`, `readBadgeList`,
    `REFRESH_COOKIE_NAME`, `resolveApiEnv`) — **dibiarkan**: bagian permukaan API
    yang dipetakan ulang oleh `scripts/audit-inventory.mjs`/`gen-api-*` terhadap
    OpenAPI backend bila spec dipulihkan; penghapusan berisiko membuat audit
    kontrak ketat (`npm run check:api`) tidak sinkron. Dicatat, bukan dihapus.
